Scarab rarity drop weights

Relative drop frequency per rarity (common = 1). Rarer scarabs get a smaller weight so they count less toward each mechanic's Wtd Avg (the rarity-weighted expected value of a random drop). Raw prices are never changed. Edits apply instantly.

Ignored gems: 0 — sent to the bottom & greyed out. Use the ⊘ next to a gem's name to ignore it.

Set your double-corrupt cost

A Temple double corrupt (Locus of Corruption) isn't free — it costs currency to run. Enter what it costs you so the Double EV columns aren't over-optimistic. You can change it anytime in ⚙ Settings.

Cost model: buy a level 1 / 0q gem, level it yourself (free), use GCPs for quality. Corruption targets a +1 level gem (21 for standard gems). EV/attempt already accounts for the resale of failed corruptions. Double-click any price cell to set a manual override; clear it to go back to the API price. All settings & overrides are saved in your browser. The Conf column rates price reliability — ● high / ● medium / ● low, from how many poe.ninja listings back the price (hover for the breakdown); the Confidence filter hides thin gems.
